# NOVA — منصة العمل الحر

🌐 **افتح المنصة مباشرة من المتصفح:**
https://nova-freelance-platform.onrender.com/

لا تحتاج إلى تنزيل أو تثبيت أي برنامج. افتح الرابط أعلاه من الهاتف أو الكمبيوتر.

منصة عربية للعمل الحر مبنية باستخدام Next.js 15 وPostgreSQL، ومستضافة على Render.

## الوظائف المتصلة بقاعدة البيانات

- إنشاء الحسابات وتسجيل الدخول والجلسات الآمنة.
- دليل مستقلين مع ملفات مهنية ونبذة ومهارات.
- نشر الخدمات كمسودات ثم نشرها أو إيقافها، مع معرض حتى 5 صور.
- إعداد باقات أساسية وقياسية واحترافية، ومدة تسليم وعدد تعديلات لكل باقة.
- طلب الخدمات ومتابعة قبولها وتنفيذها وتسليمها وطلب التعديل وإكمالها.
- تقييم الخدمة بعد اكتمال الطلب فقط؛ كل طلب يمكن تقييمه مرة واحدة.
- نشر المشاريع واستعراضها، وتقديم عروض الأسعار ومدة التنفيذ، وقبول/رفض العروض.
- صندوق تذاكر دعم خاص للعميل والإدارة، مع ردود متبادلة وحالات للتذكرة.
- إشعارات داخل المنصة عند وصول رد دعم أو طلب خدمة أو تحديث عرض/طلب.
- تواصل عام وخاص مع صور ومستندات مدعومة فقط؛ معاينة الصور وتنزيل الملفات.
- مساعد NOVA الذكي باستخدام مفاتيح المزودين المعرفة في بيئة Render.
- ترحيل جداول قاعدة البيانات تلقائياً عند أول طلب يعتمد على قاعدة البيانات.

## إعداد إدارة NOVA على Render

1. سجّل حساب NOVA بالبريد الذي سيستخدمه مدير المنصة.
2. افتح Render ثم خدمة nova-freelance-platform ثم Environment.
3. أنشئ متغيراً باسم NOVA_ADMIN_EMAILS وضع فيه البريد المسجل نفسه. يمكن وضع عدة عناوين مفصولة بفواصل.
4. احفظ التغيير وانتظر إعادة النشر، ثم سجّل الخروج والدخول من حساب الإدارة.
5. ستظهر مساحة صندوق الإدارة، وتعرض التذاكر الواردة وتسمح بالرد وتغيير حالتها.

لا تضع كلمات المرور أو مفاتيح API في GitHub أو ملفات الواجهة. قائمة بريد الإدارة تُقرأ من إعدادات الخادم فقط.

## حدود الصور والملفات

- معرض الخدمة: حتى 5 صور JPG/JPEG/PNG/GIF/WEBP، 3MB للصورة و12MB إجمالاً.
- رسائل التواصل: حتى 4 مرفقات للرسالة، 8MB لكل صورة أو مستند، و20MB إجمالاً.
- أنواع المراسلات: صور JPG/JPEG/PNG/GIF/WEBP ومستندات PDF/DOCX/XLSX/PPTX/TXT/CSV. لا يوجد دعم للفيديو.
- الصور تظهر ضمن الرسالة أو صفحة الخدمة؛ المستندات تُنزّل باسم الملف الأصلي بعد تنظيفه.
- المرفقات تحفظ حالياً في PostgreSQL بصيغة bytea. هذا حد تجريبي محدود؛ ينبغي الانتقال إلى Object Storage قبل رفع الاستخدام العام.

## وظائف تتطلب تكملة قبل الإطلاق التجاري

- طلبات الخدمات وسير التنفيذ لا تحصّل أموالاً؛ لا يوجد دفع إلكتروني أو Escrow أو تحويل/سحب أرباح متصل.
- لا يوجد تحقق بريد إلكتروني أو استرداد كلمة مرور أو توثيق هوية مكتمل.
- إشعارات الردود حالياً داخل المنصة، ولا ترسل بريداً أو SMS خارجياً.
- يلزم تخزين وسائط خارجي، وفحص ملفات ضارّة، ومحددات معدل موزعة، ومراجعة أمنية شاملة.
- يلزم اختبار عملي لحساب عميل وحساب مستقل وحساب مدير على Render بعد نشر آخر التغييرات.

## التطوير المحلي

يتطلب Node.js 20+ وPostgreSQL. انسخ .env.example إلى .env واضبط DATABASE_URL وSESSION_SECRET، ثم شغّل:

```bash
npm install
npm run dev
```

لا ترفع ملفات .env أو مفاتيح Render أو مزودي AI إلى المستودع.
