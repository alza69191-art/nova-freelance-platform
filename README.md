# NOVA — منصة العمل الحر

منصة عربية للعمل الحر مبنية باستخدام Next.js 15 وPostgreSQL، ومهيأة للتشغيل على Render.

## الوظائف الموجودة في التطبيق

- تسجيل الحسابات وتسجيل الدخول والجلسات الآمنة باستخدام scrypt وملف ارتباط HttpOnly.
- استكشاف الخدمات المنشورة والبحث عنها وتصنيفها.
- إنشاء الخدمات كمسودات، ونشرها أو إيقافها، وإضافة معرض صور JPG/PNG/GIF/WEBP.
- إعداد حتى ثلاث باقات للخدمة، مع مدد التسليم وعدد التعديلات.
- تقديم طلبات الخدمات ومتابعتها عبر حالات: مطلوب، مقبول، قيد التنفيذ، تم التسليم، طلب تعديل، مكتمل أو ملغى.
- نشر المشاريع المفتوحة واستعراضها.
- مراسلات عامة وخاصة مع إرفاق الصور والمستندات المدعومة، ومعاينة الصور وتنزيل الملفات.
- تذاكر دعم خاصة؛ يمكن للعميل متابعة الردود، ويمكن للإدارة استقبال التذاكر والرد عليها وتغيير حالتها.
- مساعد NOVA الذكي عبر مزودي AI المضافين إلى متغيرات Render.
- ترحيل جداول قاعدة البيانات تلقائياً عند أول طلب يعتمد على قاعدة البيانات.

## تفعيل صندوق الإدارة على Render

1. أنشئ حساب NOVA بالبريد الذي سيستخدمه مدير المنصة.
2. في Render افتح خدمة الويب ثم Environment.
3. أضف المتغير NOVA_ADMIN_EMAILS واجعل قيمته البريد نفسه المستخدم لتسجيل الدخول. يمكن وضع أكثر من بريد مفصول بفاصلة.
4. احفظ التغيير وانتظر اكتمال إعادة النشر، ثم سجّل الخروج والدخول من حساب المدير.
5. ستظهر مساحة صندوق الإدارة، كما سيتاح صندوق التذاكر الإداري داخل الدعم الفني.

لا تضع قائمة المديرين في ملفات الواجهة أو في GitHub أو في مستودع عام. القائمة تُقرأ من بيئة الخادم فقط.

## الملفات والتخزين

- صور الخدمات: حتى 5 صور، بحد أقصى 3MB للصورة و12MB للمجموعة.
- مرفقات المحادثات: حتى 4 ملفات في الرسالة، 8MB لكل صورة أو مستند، و20MB للمجموعة.
- أنواع المحادثات: JPG/JPEG/PNG/GIF/WEBP، وPDF/DOCX/XLSX/PPTX/TXT/CSV. ملفات الفيديو غير مدعومة في المحادثات.
- تُحفظ المرفقات في PostgreSQL بصيغة bytea. هذا مناسب لنسخة تجريبية محدودة، وليس لتخزين مكتبة وسائط كبيرة. استخدم Object Storage قبل الإطلاق على نطاق واسع.

## حدود يجب عدم الخلط بينها وبين وظائف مكتملة

- طلب الخدمة يسجل موافقة العميل والمستقل وسير التنفيذ فقط؛ لا يوجد تحصيل أموال أو Escrow أو تحويل أرباح أو سحب بنكي متصل.
- حالة مكتمل في الطلب تعكس سير العمل داخل المنصة، ولا تثبت أن NOVA استلمت أو حررت دفعة.
- رسائل الدعم والتنبيهات تُقرأ من قاعدة البيانات داخل المنصة؛ لا يوجد بريد إلكتروني خارجي أو SMS ما لم يتم ربط مزود إشعارات منفصل.
- المشاريع المفتوحة قابلة للنشر والاستعراض، لكن نظام عروض الأسعار والمقترحات المتقدم للمشاريع لم يكتمل بعد.
- لا يوجد تحقق بريد إلكتروني أو استرداد كلمة مرور أو مراجعة هوية أو نظام تقييمات ومكافحة احتيال مكتمل.
- يجب إضافة تخزين ملفات خارجي وفحص أمني تلقائي للملفات، ومحددات معدل موزعة، واختبارات أمنية ووظيفية قبل الإطلاق العام.

## إعداد التطوير المحلي

يتطلب Node.js 20+ وPostgreSQL. انسخ ملف .env.example إلى .env ثم عيّن DATABASE_URL وSESSION_SECRET، وشغّل:

```bash
npm install
npm run dev
```

لا تحفظ مفاتيح Render أو مزودي AI في المستودع.
