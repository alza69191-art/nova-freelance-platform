# NOVA — منصة العمل الحر

منصة عربية للعمل الحر مبنية باستخدام Next.js 15 وPostgreSQL، ومهيأة لتشغيل الموقع وقاعدة البيانات على Render دون Supabase.

## النشر على Render
1. افتح Render Dashboard ثم اختر **New > Blueprint**.
2. اربط المستودع `alza69191-art/nova-freelance-platform`.
3. راجع الموارد التي يعرّفها `render.yaml` ثم اضغط Apply/Sync لإنشاء خدمة الويب وقاعدة PostgreSQL.
4. Render يمرر `DATABASE_URL` إلى الموقع داخلياً، ويولّد `SESSION_SECRET` تلقائياً. لا تنسخ كلمة مرور قاعدة البيانات إلى GitHub أو المتصفح.
5. بعد اكتمال النشر افتح `/api/health` للتأكد من اتصال التطبيق بقاعدة البيانات.

## الموجود في هذه الدفعة
- واجهة عربية RTL متجاوبة وهوية بيضاء وبرتقالية.
- PostgreSQL مُعرّف كموارد Render Blueprint.
- اتصال قاعدة البيانات عبر متغير بيئة خاص بالخادم.
- إنشاء الجداول والفهارس تلقائياً عند أول طلب يعتمد على قاعدة البيانات.
- تسجيل حساب بالبريد وكلمة مرور، وتخزين كلمة المرور باستخدام scrypt.
- جلسات عشوائية مخزنة بصيغة HMAC في قاعدة البيانات، وملف ارتباط HttpOnly وSameSite.
- نقاط API لفحص صحة قاعدة البيانات والتسجيل والدخول والخروج والتحقق من الجلسة.

## تنبيه مهم حول الخطة المجانية
قاعدة Render PostgreSQL المجانية تنتهي بعد 30 يوماً، وسعتها 1GB ولا توفر نسخاً احتياطية مُدارة. استخدمها للاختبار فقط، ثم رقِّ قاعدة البيانات إلى خطة مدفوعة قبل تخزين بيانات مستخدمين حقيقية. راجع [قيود Render المجانية](https://render.com/docs/free).

## ما لم يكتمل بعد
- لم يتم ربط جميع أقسام الواجهة بعمليات قاعدة البيانات؛ بطاقات الخدمات الحالية توضيحية.
- رفع الملفات والمحادثات والطلبات والعروض والدعم الفني ولوحة الإدارة لم تكتمل بعد.
- لا يوجد دفع أو Escrow أو سحب أرباح فعلي.
- التسجيل الحالي لا يثبت ملكية البريد الإلكتروني؛ يلزم إضافة تحقق بريد قبل الإطلاق العام.
- يلزم إضافة تحديد محاولات الدخول، حماية CSRF ملائمة، CAPTCHA عند الحاجة، واختبارات أمنية ووظيفية.
- لم يتم تنفيذ نشر Render أو التحقق من نجاح build حتى الآن.

## التطوير المحلي
يتطلب Node.js 20+ وPostgreSQL. انسخ `.env.example` إلى `.env` وضع `DATABASE_URL` و`SESSION_SECRET` محلياً، ثم نفّذ:

```bash
npm install
npm run dev
```
