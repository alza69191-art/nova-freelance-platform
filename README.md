# NOVA — منصة العمل الحر

منصة عربية للعمل الحر والخدمات والمشاريع والمنتجات الرقمية باستخدام Next.js 15 وSupabase، ومهيأة للنشر على Render.

## إعداد Supabase
1. أنشئ مشروع Supabase وشغّل ملف `database.sql` في SQL Editor.
2. فعّل Email OTP من Authentication > Providers واضبط SMTP إنتاجياً لإرسال رموز التحقق.
3. أضف رابط Render إلى Authentication > URL Configuration وRedirect URLs.
4. أضف `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY` إلى Environment في Render.
5. اربط المستودع بخدمة Render Web Service واتبع `render.yaml`.

## الموجود في هذه الدفعة
- واجهة عربية RTL متجاوبة وهوية بيضاء وبرتقالية.
- صفحات/أقسام الخدمات والمشاريع والمستقلين والسوق والمزادات والباقات والدعم.
- بحث وتصنيفات لخدمات توضيحية.
- تسجيل ودخول عبر رمز OTP بالبريد الإلكتروني من Supabase Auth.
- رفع ملفات خاص بالمستخدم إلى bucket خاص، بحد 25MB، مع سياسات RLS.
- جداول أولية للملفات الشخصية والخدمات والمشاريع والدعم والإشعارات.

## حدود يجب معرفتها قبل الإطلاق
- عروض الخدمات المعروضة حالياً بيانات توضيحية؛ لم يتم بعد بناء تدفق CRUD كامل للخدمات والطلبات والمشاريع.
- رمز التحقق عبر البريد فقط؛ لا يوجد SMS. التسليم يعتمد على إعداد SMTP وحدود Supabase.
- الرفع خاص بالمستخدم، لكن فحص الملفات ضد البرمجيات الخبيثة ومعالجتها في بيئة معزولة غير مفعّل بعد.
- لا يوجد دفع أو Escrow أو سحب أرباح فعلي في هذه الدفعة.
- لا تضع Service Role Key في المتصفح أو GitHub. المفتاح العام وحده يستخدم في العميل، والحماية تعتمد على RLS.
- قبل الإطلاق العام أضف CAPTCHA/تحديد معدلات الطلبات، سجلات تدقيق، نسخاً احتياطية، واختبارات صلاحيات واختبارات بناء فعلية.
